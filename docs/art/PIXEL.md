# 屎山 · 精致像素风

构图和规则不动。只换材质：SNES/GBA 那档精致点阵，不是糊 PS1，也不是网页圆角。

## 参考图

参考图在分支 `art/pixel-direction`（PR #1）：`play.png` / `hud.png` / `scene.png`。图不进游戏包。

稿上的窗外城市、墙上长句海报、胶囊钮不要进游戏。

## 场景（钉死）

- 水平夜间办公室。人在左露上半身，电脑在右只看见显示器背面，正面被屏幕冷光打亮。
- 小人至少占场景一半高。身体像素钉死，只许背光闪、手在敲。
- 场景按低分点阵放大（建议逻辑分辨率约 160×120，nearest-neighbor）。
- CRT 光 `#a8d4e8` 只打在脸和手上，墙用抖动阴影，不要模糊。

## HUD

- 全部硬边 9 宫窗：外 2px 亮/暗 bevel，不要圆角、不要 CSS 模糊。
- 点阵字 12px（现有 FusionPixel），三数同字号同字重。
- 屎山 `#d0d4d8`；正确 `#48d060`；Bug>0 整块底 `#3a1c1c` 字 `#d45a4a`。
- 状态牌实底，贴头顶空白：写屎山 `#d4b45a` / 改 Bug `#48d060` / 写对的 `#48d060`。
- 收工：方钮，按下内凹 bevel，热区 ≥44。
- 终端：黑底绿磷光，2px 框。
- 通关章：方章，绿边，不要圆章。
