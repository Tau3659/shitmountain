# 屎山 · 创意方案 v0

点屏幕，程序员精神改 bug；不点，他就埋头写屎山。收工看写了多少行、报了多少 bug。

仓库：https://github.com/Tau3659/shitmountain  
试玩：https://tau3659.github.io/shitmountain/

## 锁定

- 竖屏、像素风。
- 上半屏：程序员敲代码。下半屏：各种 bug 报错往上刷。
- **点击**，不是按住。点一下进入「改 bug」0.6 秒，连点续时；断点立刻回到「写屎山」。没有第三态。
- 右上【收工】独立热区，点它不算改 bug。桌面空格 = 点一下。

## 状态

| 状态 | 触发 | 程序员 | 代码 |
| --- | --- | --- | --- |
| 写屎山 | 没在焦点窗里 | 驼背狂敲 | 每秒加行，顺带产 bug |
| 改 Bug | 焦点窗内 | 坐直、屏幕干净 | 只消 bug、不写新行；bug 归零就盯着 |

职级越高，写屎山和改 bug 都更快。

## HUD

- 顶栏：职称 + 头像（初级小伙 → 中级 → 资深秃头大叔）
- 左：屎山行数；右：bug 数（>0 变红）
- 中间两个词：写屎山 / 改 Bug
- 开场三个字：「点屏幕改 bug」

## 收工

弹出本局累计：行数、bug；0 bug 盖通关章。累计不清空。

- 未满级：【晋升】速度加快、形象老一档（不要求 0 bug）／【下班】最终结算
- 满级只下班

## 不做（v0）

关卡、剧情、真实编译、横屏、按住手势。
