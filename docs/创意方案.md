# 屎山 · 创意方案 v1

点屏幕，程序员精神改 bug；不点，他就埋头写屎山。两条生涯：清流 0 bug 晋升攒钱解锁；高危带着 bug 求生，最后可能被赶出职场。

仓库：https://github.com/Tau3659/shitmountain  
试玩：https://tau3659.github.io/shitmountain/

## 锁定

- 竖屏。整界面跟 [`docs/art/PIXEL.md`](art/PIXEL.md)：硬边 9 宫方窗、点阵字 12px、色板夜灰。不要圆角、不要胶囊钮。窗外城市和墙上长句不进游戏。
- 布局：上半高度钉死，只留头像/职称/存款/头顶状态和收工。三数进下半显示器，下半吃剩余高度。上半七层仍按墙/桌/装饰/显示器背面/身体/手键盘/CRT光。下半框钉死、字可滚、扫描线。
- 场景 160×120 按 4:3 contain、nearest 放大，留边夜灰 `#1a1c1e`，不用 cover，头和 CRT 都不裁。水平夜间办公室。人在左露上半身（至少半高），电脑在右只看见显示器背面；CRT 光 `#a8d4e8` 只打脸和手，墙用抖动、不模糊。
- 人物用 DD 切片：头/身体/手+键盘/CRT 光四层。头和身钉死，只动手+键盘和 CRT 光。头层不高光烤死，闪光只叠 CRT 层。默认发色黑、卫衣灰蓝，商店皮肤可换色和配件。头像随职级三档硬边。页面不滚。
- **点击**，不是按住。点一下进入「改 bug」0.6 秒（道具可加长），连点续时；断点立刻回到「写屎山」。没有第三态。
- 右上【收工】独立热区，至少 44×44，离顶/右 12px+safe。点它不算改 bug。桌面空格 = 点一下。

## 状态

| 状态 | 触发 | 程序员 | 代码 |
| --- | --- | --- | --- |
| 写屎山 | 没在焦点窗里 | 手在敲 | 屎山 +1、bug +1；每多 1 个 bug 按职级质量扣正确行 |
| 改 Bug | 焦点窗内且 bug>0 | 身体钉死，背光可闪、手在敲 | 只消 bug |
| 写对的 | 焦点窗内且 bug=0 | 同上 | 每重写 1 行：屎山 -1、正确 +1 |
| 绩效危险 | 没在焦点窗且 bug≥40 | 同上 | 仍在写屎山，警告要被开 |
| 被开除 | bug 堆到 72 | 停手 | 本局结束 |

点着先消 bug；bug 归零才重写。不点：屎山 +、bug +。所有数不低于 0。正确被 bug 吃掉时绿块轻跳并闪红。收工单三数跟着走。

小人**不跳**。Bug 数字 >0 时整块变红；数字变化时用 transform 轻跳（占位固定，约 120ms，来了就重起）。0 bug 不跳。

## 两条生涯

点一下还是改 bug / 写屎山。收工时分叉：

| 分支 | 条件 | 晋升 | 财富 | 结局 |
| --- | --- | --- | --- | --- |
| 清流 | 收工时 0 bug | 可以晋升 | 工资高、有 0 bug 奖金、晋升奖 | 爬到架构，解锁皮肤道具 |
| 高危 | 收工时 bug>0 | 无法晋升 | 工资被 bug 罚穿 | 仍可拿混乱成就；bug 到 72 被赶出职场 |

百分百无 bug 才能点【晋升】。有 bug 只能【继续写】或【下班】。被开除保留存款/皮肤/道具/成就，职级打回初级。

## 职级

职级越高：代码输出更快、质量更高（bug 更少吃正确行）、bug 率更低、改 bug 更快、工资更高。

初级 → 中级 → 资深 → 专家 → 架构。

## 财富 / 皮肤 / 道具

下班或被开除时结算本局工资进存款。0 bug 晋升立刻发晋升奖。存款跨局保留。

- 皮肤：换卫衣颜色、墨镜、眼镜、领带、赛博发。睡衣需先拿到「优化掉」成就（被开除）。
- 道具：最多装备 2 件。减 bug 产生（美式 / ESLint / 单测 / CI），或催修已有 bug（ESLint / CI 闲时自动修）、加长焦点窗（橡皮鸭）、加快修复（单测 / 结对）。装备的道具会摆上桌面。

## 成就

清流：零缺陷、转正、清流架构、无菌室、存款、工具人、更衣柜、正确行里程碑。  
高危：优化掉、试用期结束、屎山诗人、带病上岗、回滚人生、高危作业。  
更衣柜要集齐皮肤，睡衣走高危，所以两条线都会碰到。

## HUD

- 顶栏左：职称 + 头像 + 存款（初级小伙 → 中级/资深 → 专家/架构更老）
- 三数在下半显示器里分窗同级：屎山 / 正确 / Bug。屎山 `#d0d4d8`，正确 `#48d060`，Bug>0 整块底 `#3a1c1c` 字 `#d45a4a`。终端文案加厚，随机抽，不固定循环。
- 「写屎山 / 改 Bug / 写对的 / 绩效危险」方牌实底贴头顶空白，不盖脸。收工方钮按下内凹。通关方章；开除红章。
- 开场：「点屏幕改 bug / 0 bug 才能晋升」

## 收工

弹出本局累计：当前职称、下一级、屎山、正确、bug、本局工资、存款；0 bug 盖通关章。一局内累计不清空。

- 0 bug 且未满级：【晋升】／【继续写】／【商店】／【成就】／【下班】
- 有 bug：不能晋升；【继续写】／【商店】／【成就】／【下班】
- 满级或下班 / 开除：【再来一局】／【商店】／【成就】

## 不做

关卡、剧情、真实编译、横屏、按住手势、小人跳跃。
