# 屎山 · 创意方案 v0

点屏幕，程序员精神改 bug；不点，他就埋头写屎山。收工看写了多少行、报了多少 bug。

仓库：https://github.com/Tau3659/shitmountain  
试玩：https://tau3659.github.io/shitmountain/

## 锁定

- 竖屏、像素风（画风仍占位）。
- 布局：上半人、下半报错。小人至少占场景一半高，脚钉在桌前；点屏幕不许整身抬、页面不滚。
- **点击**，不是按住。点一下进入「改 bug」0.6 秒，连点续时；断点立刻回到「写屎山」。没有第三态。
- 每次点屏幕，显示器闪一下。
- 右上【收工】独立热区，至少 44×44，离顶/右 12px+safe。点它不算改 bug。桌面空格 = 点一下。

## 状态

| 状态 | 触发 | 程序员 | 代码 |
| --- | --- | --- | --- |
| 写屎山 | 没在焦点窗里 | 手在敲 | 每秒加屎山行，顺带产 bug |
| 改 Bug | 焦点窗内且 bug>0 | 身体钉死，显示器可闪、手在敲 | 只消 bug、不写新行 |
| 写对的 | 焦点窗内且 bug=0 | 同上 | 吐绿行，计入正确行数 |

点一下先消 bug；bug 归零才吐正确代码。盯着作废。身体像素钉死：不要 lean、不要抬，只许显示器闪、手在敲。

小人**不跳**。Bug 数字 >0 时整块变红；数字变化时用 transform 轻跳（占位固定，约 120ms，来了就重起）。0 bug 不跳。

职级越高，写屎山和改 bug 都更快。

## HUD

- 顶栏左：职称 + 头像（初级小伙 → 中级 → 资深秃头大叔）
- 左：屎山行数；右：Bug 数字加大，>0 整块变红
- 「写屎山 / 改 Bug / 写对的」贴在小人头顶，不跟收工挤一行
- 开场：「点屏幕改 bug」

## 收工

弹出本局累计：当前职称、下一级叫什么、屎山行数、正确行数、bug；0 bug 盖通关章。累计不清空。

- 未满级：【晋升】速度加快、形象老一档（不要求 0 bug）／【下班】最终结算
- 满级只下班（下一级显示「满级」）

## 不做（v0）

关卡、剧情、真实编译、横屏、按住手势、小人跳跃。
