# 屎山 · 创意方案 v0

点屏幕，程序员精神改 bug；不点，他就埋头写屎山。收工看写了多少行、报了多少 bug。

仓库：https://github.com/Tau3659/shitmountain  
试玩：https://tau3659.github.io/shitmountain/

## 锁定

- 竖屏。整界面跟 [`docs/art/PIXEL.md`](art/PIXEL.md)：硬边 9 宫方窗、点阵字 12px、色板夜灰。不要圆角、不要胶囊钮。窗外城市和墙上长句不进游戏。
- 布局：上半高度钉死，只留头像/职称/头顶状态和收工。三数进下半显示器，下半吃剩余高度。上半七层仍按墙/桌/装饰/显示器背面/身体/手键盘/CRT光。下半框钉死、字可滚、扫描线。
- 场景 160×120 nearest。水平夜间办公室。人在左露上半身（至少半高），电脑在右只看见显示器背面；CRT 光 `#a8d4e8` 只打脸和手，墙用抖动、不模糊。
- 人物用 DD 切片：头/身体/手+键盘/CRT 光四层。头和身钉死，只动手+键盘和 CRT 光。头层不高光烤死，闪光只叠 CRT 层。发色黑、卫衣灰蓝。头像三档同一套硬边。页面不滚。
- **点击**，不是按住。点一下进入「改 bug」0.6 秒，连点续时；断点立刻回到「写屎山」。没有第三态。
- 右上【收工】独立热区，至少 44×44，离顶/右 12px+safe。点它不算改 bug。桌面空格 = 点一下。

## 状态

| 状态 | 触发 | 程序员 | 代码 |
| --- | --- | --- | --- |
| 写屎山 | 没在焦点窗里 | 手在敲 | 屎山 +1、bug +1；每多 1 个 bug 正确 -1 |
| 改 Bug | 焦点窗内且 bug>0 | 身体钉死，背光可闪、手在敲 | 只消 bug |
| 写对的 | 焦点窗内且 bug=0 | 同上 | 每重写 1 行：屎山 -1、正确 +1 |

点着先消 bug；bug 归零才重写，每重写 1 行屎山 -1、正确 +1。不点：屎山 +、bug +，每多 1 个 bug 正确 -1。所有数不低于 0。正确被 bug 吃掉时绿块轻跳并闪红。收工单三数跟着走。

小人**不跳**。Bug 数字 >0 时整块变红；数字变化时用 transform 轻跳（占位固定，约 120ms，来了就重起）。0 bug 不跳。

职级越高，写屎山和改 bug 都更快。

## HUD

- 顶栏左：职称 + 头像（初级小伙 → 中级 → 资深秃头大叔）
- 三数在下半显示器里分窗同级：屎山 / 正确 / Bug。屎山 `#d0d4d8`，正确 `#48d060`，Bug>0 整块底 `#3a1c1c` 字 `#d45a4a`。终端文案加厚，随机抽，不固定循环。
- 「写屎山 / 改 Bug / 写对的」方牌实底贴头顶空白，不盖脸。收工方钮按下内凹。通关方章。
- 开场：「点屏幕改 bug」

## 收工

弹出本局累计：当前职称、下一级叫什么、屎山行数、正确行数、bug；0 bug 盖通关章。累计不清空。

- 未满级：【晋升】速度加快、形象老一档（不要求 0 bug）／【下班】最终结算
- 满级只下班（下一级显示「满级」）

## 不做（v0）

关卡、剧情、真实编译、横屏、按住手势、小人跳跃。
