# 屎山 · 创意方案 v1

点屏幕，程序员精神改 bug；不点，他就埋头写屎山。MVP：一套皮肤、一套桌面装饰、一个夜间办公室。两条生涯：清流 0 bug 晋升；高危带着 bug 求生，最后可能被赶出职场。

仓库：https://github.com/Tau3659/shitmountain  
试玩：https://tau3659.github.io/shitmountain/

## 锁定

- 竖屏。整界面跟 [`docs/art/PIXEL.md`](art/PIXEL.md)：硬边 9 宫方窗、点阵字 12px、色板夜灰。不要圆角、不要胶囊钮。窗外城市和墙上长句不进游戏。
- 布局：上半高度钉死，只留头像/职称/存款/头顶状态和收工。三数进下半显示器，下半吃剩余高度。上半七层仍按墙/桌/装饰/显示器背面/身体/手键盘/CRT光。下半框钉死、字可滚、扫描线。
- 场景 160×120 按 4:3 contain、nearest 放大，留边夜灰 `#1a1c1e`，不用 cover，头和 CRT 都不裁。水平夜间办公室。人在左露上半身（至少半高），电脑在右只看见显示器背面；CRT 光 `#a8d4e8` 只打脸和手，墙用抖动、不模糊。
- 人物用 DD 切片：头/身体/手+键盘/CRT 光四层。头和身钉死，只动手+键盘和 CRT 光。头层不高光烤死，闪光只叠 CRT 层。发色黑、卫衣灰蓝，**只有这一套**。头像随职级三档硬边（小伙 / 中年 / 大叔），不换装。页面不滚。桌面只留杯和纸，不另摆道具模型。
- **点击**，不是按住。点一下进入「改 bug」0.6 秒（道具可加长），连点续时；断点立刻回到「写屎山」。没有第三态。
- 右上【收工】独立热区，至少 44×44，离顶/右 12px+safe。点它不算改 bug。桌面空格 = 点一下。

## 状态

| 状态 | 触发 | 程序员 | 代码 |
| --- | --- | --- | --- |
| 写屎山 | 没在焦点窗里 | 手在敲 | 屎山 +1、bug +1；终端刷 bug 代码和独白 |
| 改 Bug | 焦点窗内且 bug>0 | 身体钉死，背光可闪、手在敲 | 只消 bug |
| 写对的 | 焦点窗内且 bug=0 | 同上 | 每重写 1 行：屎山 -1、正确 +1 |
| 绩效危险 | 没在焦点窗且 bug≥40 | 同上 | 仍在写屎山，警告要被开 |
| 被开除 | bug 堆到 72 | 停手 | 本局结束 |

点着先消 bug；bug 归零才重写。不点：屎山 +、bug +。所有数不低于 0。正确被 bug 吃掉时绿块轻跳并闪红。

小人**不跳**。Bug 数字 >0 时整块变红；数字变化时用 transform 轻跳。0 bug 不跳。

写屎山时从 100 条 bug 里随机抽：一行代码 + 一行当时的独白。文案在 [`js/bugs.js`](../js/bugs.js)。

## 两条生涯

| 分支 | 条件 | 晋升 | 财富 | 结局 |
| --- | --- | --- | --- | --- |
| 清流 | 收工时 0 bug | 可以晋升 | 工资高、有 0 bug 奖金、晋升奖 | 沿研发阶梯往上爬 |
| 高危 | 收工时 bug>0 | 无法晋升 | 工资被 bug 罚穿 | 仍可拿混乱成就；bug 到 72 被赶出职场 |

百分百无 bug 才能点【晋升】。有 bug 只能【继续写】或【下班】。被开除保留存款/道具/成就，职级打回实习生。

## 职级（24 档）

职级越高：代码输出更快、质量更高（bug 更少吃正确行）、bug 率更低、改 bug 更快、工资更高。

实习生 → 试用 → 初级 I / II / III → 中级 I / II / III → 高级 I / II / III → 资深 I / II / III → 专家 I / II / III → 主任工程师 → 架构师 → 高级架构 → 首席架构 → 技术专家 → 技术总监 → CTO

头像：实习生到中级 III 用小伙；高级到专家 II 用中年；专家 III 起用大叔。

## 财富 / 道具

下班或被开除时结算本局工资进存款。0 bug 晋升立刻发晋升奖。存款跨局保留。

道具最多装备 2 件，只改数值，不换场景：美式 / ESLint / 单测 / CI 少造 bug；橡皮鸭加长焦点；结对加快修复；ESLint / CI 闲时催修。不做皮肤商店。

## 成就

清流：零缺陷、转正、挂架构、交椅、无菌室、存款、工具人、正确行里程碑。  
高危：优化掉、试用期结束、屎山诗人、带病上岗、回滚人生、高危作业。

## HUD

- 顶栏左：职称 + 头像 + 存款
- 三数在下半显示器：屎山 / 正确 / Bug
- 状态牌：写屎山 / 改 Bug / 写对的 / 绩效危险
- 开场：「点屏幕改 bug / 0 bug 才能晋升」

## 收工

弹出本局累计：当前职称、下一级、屎山、正确、bug、本局工资、存款；0 bug 盖通关章。

- 0 bug 且未满级：【晋升】／【继续写】／【商店】／【成就】／【下班】
- 有 bug：不能晋升；【继续写】／【商店】／【成就】／【下班】
- 满级或下班 / 开除：【再来一局】／【商店】／【成就】

## 不做

关卡、剧情、真实编译、横屏、按住手势、小人跳跃、多皮肤、多场景、多套装饰。
